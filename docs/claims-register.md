## Banned Phrases & Enforcement Rules

The automated validator `scripts/check_claims.py` checks all markdown and submission files to ensure none of the following banned phrases appear:

1. `"on-prem"` / `"on-premises"`: Incorrect deployment descriptor. Must use *"private deployment on AMD infrastructure"*.
2. `"every penny"`: Hyperbolic marketing claim. Must use specific audit findings.
3. `"100% accurate"` / `"100% accuracy"`: Overclaim for probabilistic LLMs. LLMs propose rules; deterministic Python engines calculate money.
4. `"guaranteed"`: Unwarranted legal guarantee.
