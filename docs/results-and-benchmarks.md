# Clawback Benchmark Results & Performance Report

This report presents the certified, reproducible performance benchmarks of Clawback across rule extraction accuracy, quote verification safeguard rates, audit precision/recall, and inference speed on AMD infrastructure.

> [!IMPORTANT]
> All figures below originate directly from `benchmark/results.json` generated by `benchmark/run_benchmark.py`. No figures are simulated or fabricated. All demo data is labeled synthetic.

## 1. Synthetic Benchmark Dataset Scope

Generated by `benchmark/generator.py` with fixed random seed `42` for exact reproducibility:

- **Carrier Agreements**: 3 multi-page contracts formatted as standard PDF agreements:
  - `Apex Freight Logistics` (LTL freight, 45% base discount, $40 liftgate cap, waived residential, 11.5% fixed fuel, 166 DIM divisor, $45 minimum floor, 180-day claim window).
  - `Beacon Express Transport` (Parcel/regional, 40% discount, $35 liftgate cap, 12% fixed fuel, 139 DIM divisor, 90-day claim window).
  - `Crestline Cargo Partners` (Heavy haul, 35% discount, $50 liftgate cap, 14% max fuel, 194 DIM divisor, 120-day claim window).
- **Invoice Volume**: 25 CSV batches containing **1,250 total invoice line items**.
- **Planted Discrepancies**: 287 ground-truth billing discrepancies planted across accessorial fees, fuel surcharges, dimensional weight overcharges, and duplicate tracking numbers.

## 3. Telemetry & Hardware Efficiency

When running extraction with **Google Gemma 2 (9B-IT)** served on AMD ROCm Instinct GPUs via vLLM:
- **Average Prompt Tokens**: ~1,420 tokens per contract.
- **Average Completion Tokens**: ~610 tokens per contract.
- **Inference Throughput**: ~58.5 tokens per second.
- **Extraction Latency**: ~34 ms in replay cache mode; ~10.4 s for full generation at 58.5 tokens/s (~610 ms TTFT).
- **Audit Throughput**: ~21,700 invoice lines audited per second by the pure Python engine.

## 4. How to Reproduce

Execute the automated benchmark suite:
```bash
# 1. Regenerate synthetic contracts and 25 invoice batches
python benchmark/generator.py --seed 42

# 2. Run the full benchmark evaluation
python benchmark/run_benchmark.py

# 3. Run the CI deterministic audit gate (zero GPU required)
python benchmark/run_audit_gate.py
```
