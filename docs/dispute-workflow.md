# Clawback Dispute Generation Workflow

Clawback positions dispute generation as a **copilot for the accounts payable or logistics clerk**, turning raw numerical overcharges into approval-stamped, itemized carrier claim packages.

---

## 1. The Dispute Lifecycle

```
[Audit Findings] ---> [Consolidate by Carrier] ---> [Generate Draft Dispute]
                                                              |
                                                              v
                                                   [Status: "draft"]
                                                              |
                                                              v
                                                   [Clerk Reviews Notice]
                                                              |
                                                              v
                                                [Clerk Approves Dispute]
                                                              |

                                                              |
                                          +-------------------+-------------------+
                                          |                                       |
                                          v                                       v
                             [Export Formatted Markdown]               [Export Approval-Stamped PDF]

```

## 2. Dispute Letter Structure & Schedule A Evidence

A dispute notice generated by Clawback contains two primary sections:

### Section 1: Formal Legal Notice
- **Header**: Shipper legal entity, carrier accounts receivable department, date, and invoice batch reference.
- **Notice Statement**: Formal invocation of contractual audit and billing dispute rights citing the agreement reference.
- **Financial Summary**: Total billed amount, total contracted amount, and net recoverable overcharge dollars.

### Section 2: Itemized Schedule A (Audit Evidence)
Carrier billing departments routinely reject dispute claims that lack shipment-level proof. Schedule A itemizes every single contested charge:
- **Shipment Identifier**: BOL, PRO number, or tracking number.
- **Billing Charge Code**: `LFG` (Liftgate), `RES` (Residential), `FSC` (Fuel), `FRT` (Linehaul), etc.
- **Financial Comparison**: Expected Contract Amount vs Billed Amount -> Net Overcharge.
- **Contract Citation**: Specific contract page number and verbatim clause quote.
- **Step-by-Step Proof**: Explicit arithmetic equation explaining the discrepancy.

## 3. Dynamic PDF Generation Engine (ReportLab)

To ensure dispute letters can be printed or attached as formal legal notices, Clawback includes a dynamic PDF layout engine built on ReportLab:

- **Flowable Architecture**: Uses `SimpleDocTemplate` with custom flowables (`Paragraph`, `Table`, `Spacer`, `HRFlowable`).
- **Typography & Styling**: Clean corporate typography using Helvetica, neutral dark slate (`#0F172A`), and clear heading hierarchies.
- **XML Escaping & Markdown Translation**:
  ReportLab's `Paragraph` requires valid XML. Raw Markdown strings are safely escaped:
  ```python
  def escape_xml(text: str) -> str:
      return (
          text.replace("&", "&amp;")
              .replace("<", "&lt;")
              .replace(">", "&gt;")
      )
  ```
  Bold syntax (`**text**`) is converted via regular expressions (`re.sub(r'\*\*(.*?)\*\*', r'<b>\1</b>', p)`) ensuring balanced, valid tags.
- **Table Formatting**: Discrepancy tables use alternating row backgrounds (`#F8FAFC`), explicit column widths, and cell word-wrapping.

## 4. API Endpoints

- `POST /api/disputes/generate`: Consolidates audit findings for a batch and creates a dispute letter in `draft` state.
- `GET /api/disputes/{id}`: Retrieves dispute letter details, claim totals, and full Markdown content.
- `PATCH /api/disputes/{id}`: Updates dispute status (e.g., transitions from `draft` to `approved` with clerk name).
- `GET /api/disputes/{id}/export?format=markdown`: Streams clean Markdown text for email paste.
- `GET /api/disputes/{id}/export?format=pdf`: Streams binary `application/pdf` with appropriate `Content-Disposition` attachment headers.
